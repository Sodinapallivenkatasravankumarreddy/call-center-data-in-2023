# Call Center Data in 2023

An Excel portfolio project analysing call centre performance for 2023.

## Overview
The workbook covers **1,000 customer calls** and looks at call volume, call
duration, sales value and customer satisfaction across representatives.

**Headline numbers**
- Total calls: 1,000
- Total purchase amount: 96,623
- Average satisfaction rating: 3.89
- 5-star calls: 307

## Workbook contents
| Sheet | What it holds |
|-------|---------------|
| Data | Call-level data: call number, customer ID, duration, representative, date, purchase amount, satisfaction rating, plus customer details (gender, age, city) |
| Customer centre report | The 2023 call centre report |
| Pivots | Pivot tables behind the report |
| Assets | Representative IDs and images |

## Calculated fields
- **FY**: financial year, worked out from the call date
- **Day of week**: taken from the call date
- **Duration Bucket**: groups calls by length
- **Rating rounded**: satisfaction rating rounded to a whole number

## Skills demonstrated
Excel tables, formulas, pivot tables, slicers, data cleaning and reporting.
